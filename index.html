饮食调整规则 按结果微调

体重不涨，力量也不涨每天加一个：半碗米饭、一个馒头、一个香蕉、一杯牛奶或一个紫薯。

完整训练动作

周一：推 + 腹。俯卧撑 / 上斜俯卧撑 4 组 x 8-15 次；侧平举 4 组 x 12-20 次；卷腹 3 组 x 15-20 次；反向卷腹 3 组 x 10-15 次。

周二：拉 + 体态。引体辅助 / 下拉 / 门框划船 4 组 x 6-12 次；俯身划船 4 组 x 8-15 次；反向飞鸟 3 组 x 12-20 次；平板支撑 3 组 x 30-60 秒。

周三：休息 / 散步 / 收拾屋子。散步 20-40 分钟，拉伸 5-10 分钟，目标是恢复。

周四：推 + 腹。俯卧撑 / 上斜俯卧撑 4 组 x 8-15 次；肩推 / 书包肩推 3 组 x 8-12 次；侧平举 3 组 x 12-20 次；Hollow hold / 平板支撑 3 组 x 20-40 秒。

周五：拉 + 臀腿 + 核心。划船 4 组 x 8-15 次；引体辅助 / 下拉 4 组 x 6-12 次；臀桥 / 深蹲二选一 3 组 x 12-20 次；死虫 / 平板支撑 3 组。

周六 / 周日：休息。散步、拉伸、整理房间、肩颈放松。不要疯狂跑步。

观察身体变化
  • 体重每周测 3 次：早上起床、上厕所后、空腹测，看一周平均。
  • 腰围每周测 1-2 次：早上空腹测，同一个位置，目标 71-73cm。
  • 照片每周拍 1 次：同房间、同灯光、同距离，正面、侧面、背面各一张。
  • 训练记录看 4-8 周：腰围差不多，力量涨了，照片变好看了，就是方向对。
